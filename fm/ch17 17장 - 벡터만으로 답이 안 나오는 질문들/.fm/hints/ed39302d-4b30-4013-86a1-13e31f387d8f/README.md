# 도구를 고르기 전에 무엇을 먼저 해야 하는가?

**답: 질문을 세어야 한다.** 같은 성능표에 다른 질문 분포를 곱하면 결론이 반대가 되고, 질문 로그 100건이면 반나절에 답이 나온다.

## 왜 "질문 세기"가 먼저인가

17장의 도입부가 이 카드의 배경이다. GraphRAG를 붙였더니 가중 평균 정확도가 0.833 → 0.862로 **3% 올랐는데**, 그 대가로 색인 비용이 월 30만 원 늘고, 지연이 340ms 붙고, 갱신 파이프라인을 새로 만들어야 했다. "GraphRAG가 좋다더라"는 소문만 듣고 도구부터 고르면 이런 계산을 도입 **후에** 하게 된다. 순서를 뒤집어서, 우리 조직에 들어오는 질문이 어떤 유형으로 몇 %씩 분포하는지를 먼저 세는 것이 이 장의 핵심 주장이다.

## 같은 성능표, 반대 결론 — 분포가 곱해지는 방식

예제 5(`ex5_eval_harness.py`)가 이것을 숫자로 보여 준다. 질문 유형별 정확도 표는 **하나로 고정**되어 있다:

| 질문 유형 | 벡터만 | 그래프 붙임 | 차이 |
|---|---|---|---|
| 사실조회 | 0.91 | 0.89 | −0.02 ← 오히려 나빠짐 |
| 단일요약 | 0.88 | 0.85 | −0.03 |
| 다중홉 | 0.47 | 0.78 | +0.31 |
| 비교 | 0.39 | 0.74 | +0.35 |
| 전역집계 | 0.18 | 0.71 | +0.53 |

여기에 조직별 **질문 분포**를 가중치로 곱하면:

- **A 조직 (사실 조회 위주)**: 사실조회 62% + 단일요약 24%가 대부분. 가중 평균은 벡터만 0.833 vs 그래프 0.862, 차이 **+0.029** — 오차 범위 수준이라 복잡도·지연·갱신 비용을 생각하면 **붙이지 마라**가 결론.
- **B 조직 (분석 위주)**: 다중홉 28%, 비교 19%, 전역집계 18%. 차이 **+0.240** — 명확하게 **붙일 값 있음**.

성능표는 한 장인데 결론이 정반대다. 즉 "GraphRAG가 좋은가?"는 잘못된 질문이고, **"우리 질문 분포에서 좋은가?"**가 맞는 질문이다.

## 놓치기 쉬운 함정: 빈도 × 지표 변화

그래프를 붙이면 사실 조회가 0.02쯤 **나빠진다**. 작아 보이지만 사실 조회는 빈도가 가장 높은 유형이라 사용자 체감이 크다. 이것이 장 도입부의 "GraphRAG를 붙였는데 사용자 만족도가 떨어졌습니다"의 정체다. 지표 변화는 반드시 빈도를 곱해서 봐야 한다.

## 비용은 얼마인가: 질문 로그 100건, 반나절

이 결정에 필요한 재료는 거창하지 않다.

1. 실제 질문 로그 **100건**을 뽑는다.
2. 유형별(사실조회 / 단일요약 / 다중홉 / 비교 / 전역집계)로 분류해 분포를 만든다.
3. 각 방식을 돌려 유형별 정확도를 잰다.
4. 분포 × 정확도로 가중 평균을 낸다.

이 작업이 **반나절**이면 끝나고, 그 반나절이 몇 달짜리 도입 결정(그리고 월 단위의 운영 비용)을 좌우한다. 예제 3의 선택 순서도 같은 원칙에서 출발한다: "1. 질문 분포를 센다 → 2. 전역 질문이 5% 미만이면 벡터만 — 여기서 끝나는 경우가 많다."

## 기억할 한 줄

> 도구는 성능표가 아니라 **성능표 × 우리 질문 분포**로 고른다. 분포를 모르면 도구를 고를 수 없고, 분포는 질문 로그 100건이면 반나절에 나온다.

# 모델에게 "끝났나요?"를 묻지 마세요

**Q. 모델에게 "끝났나요?"를 묻지 말아야 하는 이유와 대안은 무엇인가?**

**A.** 종료 판단을 모델에게 맡기면 안 되므로 **"무엇이 남았나요"만 묻고, 끝났는지는 코드가 정한다.** 그러면 남은 목록이 진전 척도도 된다.

---

## 1. 한 줄로 먼저

> 모델에게는 **관찰**을 시키고, **판정**은 코드가 한다.
> "끝났나요?"는 판정을 시키는 질문이고, "무엇이 남았나요"는 관찰을 시키는 질문이다.

20장 「한 장 요약」의 세 번째 줄이 그대로 이 카드입니다.

> 모델에게 「끝났나요?」를 묻지 마세요. 「무엇이 남았나요」만 묻고, 끝났는지는 코드가 정합니다. 그러면 남은 목록이 진전 척도도 됩니다.

---

## 2. 왜 "끝났나요?"가 나쁜 질문인가

### 2.1 그건 자기 보고다 — 모델이 스스로 올릴 수 있는 값

20장이 진전 척도를 고를 때 내세우는 단 하나의 기준이 있습니다.

> **「모델이 스스로 올릴 수 있는 값이면 안 된다.」**

`ex2_stall_detection.py`가 같은 루프를 세 척도로 재 보는 실험입니다.

| 회차 | 위반 건수 | 산출물 길이 | 모델 확신도 |
|---:|---:|---:|---:|
| 1 | 9 | 320 | 0.55 |
| 2 | 6 | 480 | 0.61 |
| 3 | 4 | 610 | 0.68 |
| 4 | **4** | 890 | 0.74 |
| 5 | **4** | 1240 | 0.79 |
| 6 | 3 | 1610 | 0.83 |

4~5회차를 보세요. **위반은 4에서 안 줄었는데 길이와 확신도는 계속 오릅니다.**

- **산출물 길이**는 영원히 안 멈춥니다. 계속 길어지니까요. 그런데 길어지는 게 나아지는 건 아닙니다.
- **모델 확신도**도 계속 오릅니다. 15장에서 봤듯 자기 보고는 믿을 게 못 됩니다.
- **위반 건수**만 4회차에서 정체를 잡습니다. 규칙으로 세는 값이라 안 흔들립니다.

"끝났나요?"에 대한 모델의 대답은 정확히 **확신도와 같은 종류의 값**입니다. 모델이 마음대로 올릴 수 있고, 실제로 올립니다. 특히 루프가 길어지면 "이제 됐습니다"라고 말할 유인이 커져요.

### 2.2 불리언 하나는 정보가 너무 적다

"끝났나요?" → `True`/`False`. 여기서 얻는 게 1비트뿐입니다.

- `False`라도 **얼마나 남았는지**를 모릅니다. → 진전을 잴 수 없습니다.
- 진전을 못 재면 **정체(stall)를 감지할 수 없습니다.** 20장의 네 가지 종료 조건 중 「진전 없음」이 통째로 사라집니다.
- `True`가 왔을 때 **검증할 수단이 없습니다.** 거짓말인지 아닌지 확인할 근거가 답 안에 없어요.

`guards.py`의 주석이 같은 지적을 종료 사유에 대해 합니다.

> 불리언 하나만 돌려주면 호출한 쪽이 다르게 대응할 수 없다.

### 2.3 종료 판단을 모델에게 맡기면 = 종료 조건이 없는 것

1장의 41만 원짜리 사고를 요약한 문장이 이겁니다.

> "종료 조건이 없으면 종료를 모델이 정한다."

"끝났나요?"만 물어보는 루프는 종료 조건이 **있어 보이지만** 실은 없는 상태입니다. 판정 주체가 결국 모델이니까요.

## 3. 대안: "무엇이 남았나요"

### 3.1 구조

```
모델/검증기 →  남은 것들의 목록 (missing)
              ↓
코드      →  len(missing) == 0 ?  → 종료
              len(missing) 이력 → 진전 척도 → 정체 감지
```

세 가지가 한 번에 나옵니다.

1. **종료 판정** — 목록이 비었나. 코드가 봅니다.
2. **진전 척도** — 목록 길이. 회차마다 줄어드나.
3. **인계 정보** — 못 끝냈을 때 "정확히 무엇이 안 됐는지"가 사람에게 그대로 넘어갑니다.

### 3.2 책의 구현 (`ex4_generator_critic.py`)

체크리스트를 코드 쪽에 고정해 둡니다.

```python
REQUIRED = ["## 개요", "## 원인", "## 조치", "## 재발 방지"]
```

검증 단계는 **판정하지 않고 목록만 만듭니다.**

```python
def critic(s: S) -> dict:
    miss = [x for x in REQUIRED if x not in s["text"]]
    return {"missing": miss, "scores": [len(miss)]}
```

- `missing` — 무엇이 남았나
- `scores` — 그 길이. 진전 척도가 **공짜로** 따라 나옵니다.

끝났는지는 **코드가** 정합니다.

```python
def route(s: S) -> str:
    if not s["missing"]:          # ← 종료 판정. 모델이 아니라 코드가 한다
        return "성공"
    if s["rounds"] >= MAX_ROUNDS:
        return "상한"
    if s["cost"] >= MAX_COST:
        return "예산"
    if stalled(s["scores"]):      # ← 같은 목록으로 정체까지 잡는다
        return "정체"
    return "생성"
```

`stalled()`가 보는 게 `scores`, 즉 **남은 목록의 길이 이력**입니다. "무엇이 남았나요"를 물었기 때문에 정체 감지가 가능해진 거예요.

```python
def stalled(scores):
    n = STALL_LIMIT + 1
    if len(scores) < n:
        return False
    w = scores[-n:]
    return w[-1] >= min(w[:-1])   # «같음»도 정체로 본다
```

### 3.3 실행 결과가 말해 주는 것

예제 4는 3회차부터 모델이 더 못 고치는 상황을 흉내 냅니다. 결과는 「정체」로 종료.

> 횟수 상한만 있었다면 6회차까지 돌아 132를 썼을 것이다. 정체 감지가 세 회차를 아꼈다.

**"끝났나요?"만 물었다면** 이 절약이 불가능합니다. 모델은 계속 "아니요"라고 할 것이고, 진전 척도가 없으니 정체를 못 잡고, 결국 횟수/예산 상한까지 다 태우고 끝났을 겁니다.

## 4. 실무 포인트 몇 개

### 4.1 목록 자체도 가능하면 규칙으로 뽑아라

예제 4의 `critic`은 아예 **모델을 안 씁니다.** `x not in s["text"]` — 순수 문자열 검사예요. 가능하면 이게 최선입니다. 모델이 개입할 여지가 0이니까요.

모델에게 물어야만 하는 경우(예: "논리적 비약이 남았나")라면, **미리 정한 체크리스트 항목 ID로만** 답하게 하고 자유 서술을 종료 판정에 쓰지 마세요. 목록이 열려 있으면 모델이 항목을 조용히 빼서 목록을 비울 수 있습니다.

### 4.2 진전 척도는 "낮을수록 좋은" 카운트가 편하다

`guards.py`도 `ex4`도 점수를 **위반/미충족 건수**로 잡습니다. 0이 곧 성공이고, 단조 감소가 곧 진전이라 정체 판정식이 단순해집니다.

```python
def stalled(self) -> bool:
    """«같음»도 정체로 본다. 나빠지는 것만 잡으면 늦다."""
```

「같음도 정체」가 핵심입니다. 예제 2의 4~5회차(위반 4 → 4)를 잡아내는 게 바로 이 조건이에요.

### 4.3 끝난 이유를 상태에 남겨라

목록 기반으로 바꾸면 종료 사유가 자연스럽게 갈라집니다. 대응이 각각 다릅니다.

| 종료 사유 | 대응 |
|---|---|
| 성공 | 그대로 쓴다 |
| 상한 | 사람에게 넘긴다 (더 돌리면 될 수도 있다) |
| 예산 | 예산을 올릴지 물어본다 |
| 정체 | 사람에게 넘긴다 (**더 돌려도 안 된다**) |

「상한」과 「정체」의 대응이 정반대입니다. 불리언 하나로는 이 구분이 안 됩니다.

---

## 5. 외워 둘 문장

- **판정은 코드, 관찰은 모델.**
- **"끝났나요?" → 1비트, 검증 불가, 자기 보고. "무엇이 남았나요" → 목록, 검증 가능, 진전 척도 겸용.**
- **진전 척도는 모델이 스스로 올릴 수 있는 값이면 안 된다.** (길이 ✗, 확신도 ✗, 위반 건수 ✓)
- 남은 목록이 안 줄면 그게 정체다. **같음도 정체로 본다.**

# 제약과 사건, 같은 35%인데 왜 갈렸나

**질문** — 제약과 사건의 자기 재생산율이 같은 35%인데 결과가 갈린 이유는 무엇인가?

**답** — 「남이 나를 낳아 주는」 비율이 다르다. 관계를 읽으면 사건을 쓸 확률이 15%, 제약은 5%로 세 배 차이다.

출처: 28장 4절 「아무도 시키지 않은 방향으로 자란다」 / `code/ex4_drift.py`

---

## 1. 무대 설정

`ex4_drift.py`는 에이전트가 **자기가 쓴 그래프를 다시 읽고 또 쓰는** 루프를 100세대 돌린다. 매 세대 20개를 새로 쓰는데, 쓰는 절차는 이렇다.

```python
# 에이전트가 기존 그래프에서 하나를 읽고, 그것에 이끌려 새 사실을 쓴다
seed = rng.choices(KINDS, [counts[x] for x in KINDS])[0]
emit = EMIT[seed]
k = rng.choices(KINDS, [emit[x] for x in KINDS])[0]
new[k] += 1
```

핵심은 두 단계라는 점이다.

1. **읽기** — 씨앗 `seed`를 뽑는데, 확률이 **현재 그래프의 분포에 비례**한다 (`counts` 가중치).
2. **쓰기** — 씨앗의 종류에 따라 `EMIT[seed]` 행에서 쓸 종류를 뽑는다.

즉 새로 쓰이는 종류의 확률은 `(현재 분포) × (전이행렬)`이다. 「자기 재생산율」은 이 곱의 **한 항**일 뿐이다.

시작 분포는 `START = {"관계": 40, "선호": 30, "제약": 20, "사건": 10}`.

---

## 2. 전이행렬 원문

```python
EMIT = {
    "관계": {"관계": 0.62, "선호": 0.18, "제약": 0.05, "사건": 0.15},
    "선호": {"관계": 0.20, "선호": 0.55, "제약": 0.10, "사건": 0.15},
    "제약": {"관계": 0.25, "선호": 0.20, "제약": 0.35, "사건": 0.20},
    "사건": {"관계": 0.40, "선호": 0.20, "제약": 0.05, "사건": 0.35},
}
```

표로 다시 보면 (**행 = 읽은 종류**, **열 = 쓴 종류**):

| 읽은 것 ↓ \ 쓴 것 → | 관계 | 선호 | **제약** | **사건** |
|---|---|---|---|---|
| 관계 | 0.62 | 0.18 | **0.05** | **0.15** |
| 선호 | 0.20 | 0.55 | **0.10** | **0.15** |
| 제약 | 0.25 | 0.20 | **0.35** | 0.20 |
| 사건 | 0.40 | 0.20 | 0.05 | **0.35** |

책이 지적한 대각선은 이렇다.

```
관계 → 관계 62%    제약 → 제약 35%    사건 → 사건 35%
```

대각선만 보면 제약과 사건은 **완전히 같다**. 그런데 결과는 제약 20% → 9%, 사건 10% → 19%로 정반대다.

---

## 3. 답의 자리 — 대각선이 아니라 **열**을 봐라

자기 재생산율은 행렬의 **대각 원소**다. 그 종류의 운명을 결정하는 건 대각 원소 하나가 아니라 **그 종류의 열 전체**다. 열이 「나를 낳아 주는 모든 경로」이기 때문이다.

### 3-1. 열합 비교 (분포를 무시한 순수 구조)

**제약 열**: `0.05 + 0.10 + 0.35 + 0.05 = 0.55`
**사건 열**: `0.15 + 0.15 + 0.20 + 0.35 = 0.85`

자기 항(0.35)을 빼면 「남이 나를 낳아 주는」 몫만 남는다.

| | 자기 재생산 (대각) | 남이 낳아 줌 (비대각 열합) | 열 전체 |
|---|---|---|---|
| 제약 | 0.35 | `0.05 + 0.10 + 0.05` = **0.20** | 0.55 |
| 사건 | 0.35 | `0.15 + 0.15 + 0.20` = **0.50** | 0.85 |

자기 재생산은 **동률**인데 외부 유입이 **0.20 대 0.50, 2.5배**다. 갈린 이유의 전부가 여기에 있다.

그중에서도 책이 콕 집은 것은 가장 흔한 종류인 **관계**로부터의 유입이다.

```
관계 → 사건 = 0.15
관계 → 제약 = 0.05
                → 정확히 3배
```

「관계를 읽으면 사건을 쓸 확률이 15%, 제약은 5%다. 세 배 차이다.」가 이 두 칸을 가리킨다. 그리고 관계는 처음부터 40%로 제일 많고, 관계 → 관계가 62%라 계속 제일 많다. **곱해지는 계수가 제일 큰 항에서 3배 차가 나므로** 그 차이가 세대마다 누적된다.

### 3-2. 유입(inflow) 실제 계산 — 1세대

한 번 쓸 때 종류 `k`가 나올 확률은

```
inflow(k) = Σ_s  x[s] × EMIT[s][k]        (x = 현재 분포)
```

시작 분포 `x = (관계 .40, 선호 .30, 제약 .20, 사건 .10)`을 넣는다.

**제약의 유입**

| 씨앗 | 계산 | 기여 |
|---|---|---|
| 관계 | `0.40 × 0.05` | 0.0200 |
| 선호 | `0.30 × 0.10` | 0.0300 |
| 제약 (자기) | `0.20 × 0.35` | 0.0700 |
| 사건 | `0.10 × 0.05` | 0.0050 |
| **합** | | **0.1250** |

**사건의 유입**

| 씨앗 | 계산 | 기여 |
|---|---|---|
| 관계 | `0.40 × 0.15` | 0.0600 |
| 선호 | `0.30 × 0.15` | 0.0450 |
| 제약 | `0.20 × 0.20` | 0.0400 |
| 사건 (자기) | `0.10 × 0.35` | 0.0350 |
| **합** | | **0.1800** |

### 3-3. 손익분기 — 유입을 현재 점유율과 비교한다

새로 쓰이는 것의 비율이 지금 점유율보다 낮으면 그 종류는 **묽어진다**.

| | 현재 점유율 | 유입 | 판정 |
|---|---|---|---|
| 제약 | 0.20 | **0.125** | 필요량의 62.5% → **줄어든다** |
| 사건 | 0.10 | **0.180** | 필요량의 180% → **늘어난다** |

자기 항만 보면 제약이 오히려 유리해 보인다는 게 함정이다. 제약의 자기 기여 0.0700은 사건의 0.0350의 **두 배**다. 제약이 그 시점에 두 배 많았으니 당연하다. 그런데 나머지 세 칸의 합이 제약 **0.0550** 대 사건 **0.1450**이라 뒤집힌다. 자기 재생산율이 같을 때 승부는 전적으로 외부 유입에서 난다.

### 3-4. 100세대 뒤 — 고정점

`x ← x·EMIT`을 수렴할 때까지 반복하면 (실제 스크립트는 카운트가 누적되므로 같은 고정점에 더 천천히 다가간다):

| 세대 | 관계 | 선호 | 제약 | 사건 |
|---|---|---|---|---|
| 0 (시작) | 40% | 30% | 20% | 10% |
| 1 | 39.8% | 29.7% | 12.5% | 18.0% |
| 2 | 40.9% | 29.6% | 10.2% | 19.2% |
| 5 | 41.9% | 29.5% | 9.3% | 19.3% |
| 수렴 | **41.9%** | 29.5% | **9.2%** | **19.3%** |

책의 출력 「제약이 20%에서 9%로 반토막, 사건이 10%에서 19%로 두 배, 관계는 40%에서 42%로 거의 안 변했다」와 일치한다. 1세대만 계산해도 제약 12.5% / 사건 18.0%로 **방향이 이미 결정**되어 있다는 점이 중요하다. 100세대는 이미 정해진 방향으로 굴러간 것뿐이다.

고정점에서 다시 검산해 보면 균형이 맞는다.

- 제약 유입 = `.419×.05 + .295×.10 + .092×.35 + .193×.05 = 0.092` → 점유율 9.2%와 일치
- 사건 유입 = `.419×.15 + .295×.15 + .092×.20 + .193×.35 = 0.193` → 점유율 19.3%와 일치

## 4. 책이 뽑아낸 일반 법칙

> 살아남는 종류를 정하는 건 «자기 재생산율»만이 아니라 «전체 분포와의 곱»이다. 제일 흔한 종류가 무엇을 낳느냐가 지배한다.

정리하면 **한 종류의 운명 = 그 종류의 열 벡터와 현재 분포의 내적**이다. 그러므로

- **대각선(자기 재생산율)은 한 항일 뿐**이고, 동률이어도 아무것도 말해 주지 않는다.
- **가장 흔한 종류의 행**이 사실상 결과를 좌우한다. 여기서는 관계 행이 그렇고, 관계 → 제약 0.05가 제약의 사형 선고다.
- 관계 → 관계 0.62라는 강한 자기 강화가 「관계가 계속 제일 흔함」을 보장해서, 관계 행의 지배력이 사라지지 않는다.

---

## 5. 왜 이게 무서운가

제약은 27장에서 「잃으면 제일 아픈 종류」로 다뤄진 것이다. 그런데 여기서는 **지워져서 사라지는 게 아니라 비율이 묽어져서 사라진다**. 삭제 로그도 없고 철회 기록도 없다. 조회할 때 상위 k개를 뽑으면 어느 순간부터 제약이 안 뽑히기 시작할 뿐이다.

그리고 아무도 「관계를 늘려라」라고 지시하지 않았다. 전이 구조가 그렇게 생겼기 때문에 루프를 돌리면 저절로 그렇게 된다. 이게 **그래프 드리프트**다.

## 6. 사람 개입으로는 못 막는다

`step()`은 `human_share` 확률로 사람이 원래 분포(`START`)대로 넣는 경로를 갖고 있다.

```python
if rng.random() < human_share:
    # 사람이 넣는 사실은 원래 분포를 따른다
    k = rng.choices(KINDS, [START[x] for x in KINDS])[0]
```

`x ← 0.2·START + 0.8·(x·EMIT)`의 고정점을 계산하면:

| | 관계 | 선호 | 제약 | 사건 |
|---|---|---|---|---|
| 사람 개입 0% | 41.9% | 29.5% | **9.2%** | 19.3% |
| 사람 개입 20% | 41.0% | 29.6% | **12.1%** | 17.2% |

책 그대로 「제약이 9%가 아니라 12%에서 멈춘다」. **감속은 되는데 방향은 그대로**다. 5분의 1을 사람이 넣어도 시작값 20%로 못 돌아온다. 「가끔 사람이 확인한다」로는 안 되고, 개입 비율을 절반까지 올리는 건 현실적이지 않다.

## 7. 그래서 대응은 비율에 건다

개별 사실을 검증하는 관문(28.2절의 관문 넷)은 이 문제를 못 잡는다. 드리프트로 들어오는 사실은 **하나하나가 다 맞는 사실**이기 때문이다. 잡으려면 개별 사실이 아니라 **분포**를 지표로 삼아야 한다.

- 관계가 전체의 55%를 넘으면 관계 쓰기를 멈춘다 (지배적인 행의 힘을 직접 꺾는다)
- 제약이 10% 아래로 내려가면 경보를 울린다

비율은 매일 재면 되고 쿼리 한 줄이다. 그리고 **이 지표가 없으면 묽어지는 것을 영영 못 본다.**

## 한 줄 암기

> 자기 재생산율은 **대각선 한 칸**, 운명은 **열 전체**. 제약과 사건은 대각선이 0.35로 같지만 비대각 열합이 0.20 대 0.50이고, 특히 가장 흔한 관계 행에서 0.05 대 0.15로 **세 배** 벌어져 정반대로 갈렸다.

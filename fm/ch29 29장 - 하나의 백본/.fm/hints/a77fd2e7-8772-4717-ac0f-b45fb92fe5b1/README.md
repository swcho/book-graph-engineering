# `ex5`의 세 가지 아키텍처 규칙

## 질문
`ex5`의 세 가지 아키텍처 규칙은 무엇인가?

## 답
1. **아래로만 부른다** — 순환 의존을 막는다.
2. **계층을 건너뛰지 않는다** — 오케스트레이터가 저장소를 직접 안 만진다.
3. **그래프 쓰기는 쓰기 관문을 거친다** — 관문 우회 경로를 막는다.

## 배경: 왜 "검사 가능한 아키텍처"인가

29장 29.5절의 `ex5_reference_arch.py`는 참조 아키텍처를 **그림이 아니라 검사 가능한 데이터**로 적는 예제입니다. 책의 핵심 주장은 이렇습니다.

> 그림으로만 있는 아키텍처는 6개월이면 그림과 코드가 갈라진다. 다들 "그림을 갱신하자"로 대응하지만, 그러면 또 갈라진다.

대신 계층(LAYERS)·구성 요소(COMPONENTS)·규칙(RULES)을 파이썬 데이터로 적어 두면 CI에서 자동 검사할 수 있고, 새 호출을 추가하면서 규칙을 어기면 머지가 안 됩니다. **이 파일이 곧 아키텍처 문서**이고, 그림은 이 데이터에서 "생성"하면 됩니다(반대 방향은 불가능).

## 예제의 계층 구조

```
표현 → 오케스트레이션 → 도메인 → 그래프 → 저장
```

| 구성 요소 | 계층 | 부르는 것 |
|---|---|---|
| 채팅 UI | 표현 | - |
| 리드 에이전트 | 오케스트레이션 | 작업자 A, 작업자 B, 승인 게이트 |
| 작업자 A/B | 오케스트레이션 | 문서 서비스, 그래프 게이트웨이 |
| 승인 게이트 | 오케스트레이션 | 체크포인트 저장소 (← 의도된 위반!) |
| 문서 서비스 | 도메인 | 객체 저장소 |
| 그래프 게이트웨이 | 그래프 | 그래프 DB, 벡터 색인 |
| 쓰기 관문 | 그래프 | 그래프 DB |
| 그래프 DB / 벡터 색인 / 객체 저장소 / 체크포인트 저장소 | 저장 | - |

## 세 규칙을 코드로 보면

```python
RULES = [
    ("아래로만 부른다",
     lambda a, b: RANK[COMPONENTS[b][0]] >= RANK[COMPONENTS[a][0]]),
    ("저장 계층을 건너뛰지 않는다",
     lambda a, b: not (COMPONENTS[a][0] == "오케스트레이션"
                       and COMPONENTS[b][0] == "저장")),
    ("그래프 쓰기는 쓰기 관문을 거친다",
     lambda a, b: not (b == "그래프 DB" and a not in
                       ("그래프 게이트웨이", "쓰기 관문"))),
]
```

### 규칙 1 — 아래로만 부른다
호출 대상(b)의 계층 순위가 호출자(a)보다 같거나 낮아야(=더 아래여야) 합니다. 아래 계층이 위 계층을 되부르는 순간 **순환 의존**이 생기고, 빌드·배포·장애 격리가 전부 얽힙니다.

### 규칙 2 — 계층을 건너뛰지 않는다
오케스트레이션 계층이 저장 계층을 직접 부르면 안 됩니다. 오케스트레이터가 저장소를 직접 만지면 도메인/그래프 계층의 검증·규칙이 전부 우회됩니다. 예제에는 일부러 **"승인 게이트 → 체크포인트 저장소"** 라는 위반이 심어져 있어 CI에 넣으면 여기서 실패하도록 되어 있습니다.

### 규칙 3 — 그래프 쓰기는 쓰기 관문을 거친다 (28장 연결)
그래프 DB에 쓰는 경로는 "그래프 게이트웨이"나 "쓰기 관문"뿐이어야 합니다. 책은 이 규칙이 특히 중요하다고 강조합니다.

> 관문을 만들어 놓고 우회하는 경로가 생기면 관문은 있으나 마나가 된다. 그리고 그런 우회는 «급할 때» 생긴다.

28장에서 에이전트가 그래프를 스스로 넓힐 때 쓰기 관문(검증·승인 게이트)을 세웠는데, 규칙 3은 그 관문이 우회되지 않도록 아키텍처 수준에서 강제하는 장치입니다.

## 암기 포인트

- 세 규칙은 원래 **"머릿속에만 있던 것"** — 그림에는 안 적히는 암묵지를 데이터로 명문화한 것.
- 키워드 3개로 외우기: **아래로만 / 건너뛰기 금지 / 관문 필수**.
- 각 규칙이 막는 것: **순환 의존 / 오케스트레이터의 저장소 직접 접근 / 쓰기 관문 우회**.

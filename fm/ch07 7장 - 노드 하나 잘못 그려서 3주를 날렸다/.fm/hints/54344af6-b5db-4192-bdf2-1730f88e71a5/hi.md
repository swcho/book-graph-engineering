# 투영 엣지 수의 상한 — 고등학교 수학으로

## 결론부터

투영 엣지 수의 상한은

$$n \times \frac{k(k-1)}{2}$$

$n$은 사용자 수, $k$는 1인당 구매 수다. 여기서 $\frac{k(k-1)}{2}$ 는 「확률과 통계」에서 배운 조합 $\binom{k}{2} = {}_k\mathrm{C}_2$ 다.

이 글은 이 식이 어디서 나오고, 왜 무서운지를 고교 개념만으로 쌓아 올린다.

---

## 1. 그래프란 점과 선

**그래프**는 점(**노드**, node)과 그 점들을 잇는 선(**엣지**, edge)으로 이루어진 그림이다. 「누가 무엇을 샀다」를 그림으로 그려 보자.

- 점: 사용자 `u1`, `u2`, `u3` 그리고 상품 `A`, `B`, `C`
- 선: 산 관계

```
 u1 ──── A
   \    /
    \  /
 u2 ─┼─ B
    \
     \── C
 u3 ──── C
```

여기서 중요한 성질이 하나 있다. **선은 항상 「사용자」와 「상품」 사이에만 있다.** 사용자끼리 이어지지도, 상품끼리 이어지지도 않는다.

점이 두 종류로 갈리고 선이 반드시 서로 다른 종류 사이에만 놓이는 그래프를 **이분 그래프(bipartite graph)** 라고 한다. `이분(二分)` = 둘로 나뉜다.

## 2. 투영: 한쪽만 남기기

이제 「함께 산 상품끼리 잇자」를 해 보자. 사용자는 지우고 상품끼리의 그래프를 만드는 것이다. 이걸 **투영(projection)** 이라 한다. 그림자를 한쪽 벽에만 비추는 것과 같다.

`u2`는 `A`, `B`, `C`를 셋 다 샀다. 그러면 이 세 상품은 서로 「같이 팔린 사이」다. 선을 그으면

```
   A ──── B
    \    /
     \  /
      C
```

세 개다. `A—B`, `A—C`, `B—C`.

여기서 질문. **상품 $k$개를 산 사용자 한 명은 선을 몇 개 만드는가?**

$k$개 중에서 **2개를 골라 짝짓는 모든 방법의 수**다. 순서는 상관없다 — `A—B`와 `B—A`는 같은 선이니까. 순서를 따지지 않고 $k$개에서 2개를 뽑는 것, 이게 바로 조합이다.

$$\binom{k}{2} = \frac{k!}{2!\,(k-2)!} = \frac{k(k-1)}{2}$$

직관적으로도 확인해 보자. 첫 번째 상품을 고르는 방법이 $k$가지, 두 번째는 남은 $k-1$가지. 곱하면 $k(k-1)$. 그런데 `(A, B)`와 `(B, A)`를 따로 셌으므로 2로 나눈다.

$$\frac{k(k-1)}{2}$$

$k=3$이면 $\frac{3 \times 2}{2} = 3$. 위 그림과 맞다.

## 3. 사용자 $n$명으로 확장

사용자가 $n$명이고 각자 $k$개씩 샀다. 각 사용자가 $\frac{k(k-1)}{2}$ 개의 선을 만들므로, 전부 더하면

$$\underbrace{\frac{k(k-1)}{2} + \frac{k(k-1)}{2} + \cdots + \frac{k(k-1)}{2}}_{n \text{개}} = n \times \frac{k(k-1)}{2}$$

이게 공식이다.

## 4. 왜 「상한」이라고 부르는가

**여러 사람이 똑같은 짝을 만들 수 있다.**

`u1`이 `{A, B}`를 사고 `u2`도 `{A, B}`를 샀다면, 짝 `A—B`가 두 번 만들어진다. 하지만 그래프에 선은 **하나**만 그린다. 대신 그 선에 「함께 산 사람 2명」이라는 숫자(**가중치**)를 붙인다.

그러니까 공식이 세는 것은 **만들어 본 짝의 총 횟수**이고, 실제 선의 개수는 그보다 **작거나 같다**.

$$(\text{실제 엣지 수}) \ \le\ n \times \frac{k(k-1)}{2}$$

부등호가 등호가 되는 경우는 「모든 사람이 서로 겹치는 짝을 하나도 안 만들 때」다. 현실에서는 거의 없다.

### 또 다른 상한

상품 종류가 $m$개뿐이라면, 상품끼리 가능한 짝의 개수 자체가 이미 제한된다.

$$\binom{m}{2} = \frac{m(m-1)}{2}$$

이보다 많은 선은 물리적으로 불가능하다. 그래서 진짜 상한은 둘 중 작은 쪽이다.

$$(\text{실제 엣지 수}) \ \le\ \min\!\left(n \cdot \frac{k(k-1)}{2},\ \ \frac{m(m-1)}{2}\right)$$

그래도 첫 번째 식이 중요한 건, **컴퓨터가 실제로 해야 하는 계산량**이 그 값이기 때문이다. 겹치는지 아닌지는 짝을 만들어 본 뒤에야 알 수 있다. 만들어 보는 횟수 자체는 정확히 $n \cdot \frac{k(k-1)}{2}$ 번이다.

## 5. 제곱의 무서움 — 함수로 보기

이제 $k$에 대한 함수로 보자.

$$f(k) = \frac{k(k-1)}{2} = \frac{1}{2}k^2 - \frac{1}{2}k$$

**이차함수**다. 「이차식이 일차식보다 빨리 커진다」는 것은 알고 있지만, 얼마나 빨리인지 미분으로 확인해 보자.

$$f'(k) = k - \frac{1}{2}$$

$k$가 커지면 **증가율 자체가 계속 커진다.** $k=10$에서는 상품 하나 늘 때 선이 약 9.5개 늘지만, $k=200$에서는 하나 늘 때 약 199.5개 늘어난다.

$k$가 충분히 클 때는

$$f(k) = \frac{k^2 - k}{2} \approx \frac{k^2}{2}$$

로 봐도 좋다. 그래서 **$k$가 $c$배 되면 선은 약 $c^2$배**가 된다.

### 표로 확인

$n$과 $k$를 바꿔 보자.

| 사용자 $n$ | 1인당 구매 $k$ | 상한 $n\cdot\frac{k(k-1)}{2}$ |
|---:|---:|---:|
| 1,000 | 10 | 45,000 |
| 1,000 | 50 | 1,225,000 |
| 100,000 | 50 | 122,500,000 |
| 100,000 | 200 | 1,990,000,000 |

첫 줄과 둘째 줄: **$k$만 5배** ($10 \to 50$) 했는데 선은 약 27배가 됐다. ($5^2 = 25$ 에 가깝다. $-k$ 항 때문에 살짝 다르다.)

둘째 줄과 셋째 줄: **$n$만 100배** ($1{,}000 \to 100{,}000$) 했더니 선도 정확히 100배. $n$에 대해서는 일차함수라 그렇다.

셋째 줄과 넷째 줄: **$k$만 4배** ($50 \to 200$) 했는데 약 16배. ($4^2 = 16$)

$$\text{정리:}\quad n \text{에 대해 } 1\text{차},\quad k \text{에 대해 } 2\text{차}$$

키워야 할 것과 조심해야 할 것이 확실히 다르다. 사용자가 두 배 되는 건 견딜 수 있다. **1인당 구매 수가 두 배 되면 선은 네 배**가 된다.

## 6. 평균을 쓰면 왜 항상 과소평가인가

지금까지는 「모두가 똑같이 $k$개씩 산다」고 가정했다. 현실은 다르다. 어떤 사람은 3개, 어떤 사람은 5,000개를 산다.

정확한 식은 사용자별로 따로 계산해 더하는 것이다. 사용자 $u$가 $k_u$개를 샀다면

$$(\text{짝 생성 총 횟수}) = \sum_{u} \frac{k_u(k_u-1)}{2}$$

「그럼 평균 $\bar{k}$ 를 넣으면 되겠네」 — **안 된다. 항상 과소평가가 된다.** 왜 그런지 두 사람 예로 보자.

두 사람이 각각 10개, 90개를 샀다. 평균은 50이다.

- **평균으로 계산**: $2 \times \frac{50 \times 49}{2} = 2450$
- **실제**: $\frac{10 \times 9}{2} + \frac{90 \times 89}{2} = 45 + 4005 = 4050$

실제가 훨씬 크다. 1.65배다.

이유는 $y = k^2$ 그래프의 **모양**에 있다. 이차함수 $y = k^2$ 은 위로 열린 포물선, 즉 **아래로 볼록(convex)** 하다. 아래로 볼록한 곡선에서는 곡선 위 두 점을 이은 **선분이 항상 곡선보다 위에** 있다.

$$\frac{f(a) + f(b)}{2} \ \ge\ f\!\left(\frac{a+b}{2}\right)$$

왼쪽은 「두 점의 $y$값 평균」 = 선분의 중점 높이, 오른쪽은 「$x$값 평균에서의 곡선 높이」다. 선분이 위에 있으니 왼쪽이 크다.

$f(k) = k^2$ 으로 확인해 보자. $a = 10$, $b = 90$:

$$\frac{100 + 8100}{2} = 4100 \ \ge\ 50^2 = 2500 \quad \checkmark$$

이걸 $n$개로 일반화한 것이 **옌센 부등식(Jensen's inequality)** 이다. 볼록함수에 대해

$$\frac{1}{n}\sum_{u} f(k_u) \ \ge\ f\!\left(\frac{1}{n}\sum_u k_u\right) = f(\bar{k})$$

$$\text{즉}\quad \frac{1}{n}\sum_u k_u^2 \ \ge\ \bar{k}^2$$

**등호는 모든 $k_u$가 같을 때만 성립한다.** 사람마다 구매 수가 다르면 반드시 실제가 더 크다. 그리고 편차가 클수록 격차가 벌어진다.

「확률과 통계」에서 배운 분산 공식을 쓰면 정확히 얼마나 큰지 나온다.

$$V(k) = E(k^2) - \{E(k)\}^2 \quad \Longrightarrow \quad E(k^2) = \bar{k}^2 + V(k)$$

그러니까 짝 생성 총 횟수는

$$\sum_u \frac{k_u^2 - k_u}{2} = \frac{n}{2}\left(E(k^2) - \bar{k}\right) = \frac{n}{2}\left(\bar{k}^2 + V(k) - \bar{k}\right)$$

**과소평가분이 정확히 $\frac{n \cdot V(k)}{2}$** 다. 분산이 클수록 그만큼 더 든다.

현실의 구매 수 분포는 분산이 매우 크다. 대부분은 몇 개만 사고, 극소수가 엄청나게 많이 산다(**멱법칙**, 롱테일). 봇이나 도매상 계정 하나가 상품 5만 개를 샀다면 그 계정 하나가

$$\frac{50{,}000 \times 49{,}999}{2} \approx 12.5\text{억 쌍}$$

을 만든다. 나머지 사용자 전체를 합친 것보다 클 수도 있다.

## 7. 그래서 어떻게 하나

원문(7장 예제 4)이 제시하는 대안이다.

### 대안 1: 투영하지 않고 그때그때 2홉으로

「이 상품과 함께 팔린 상품」이 궁금할 때만 원본 이분 그래프에서 두 걸음 간다.

$$(\text{상품 X}) \xleftarrow{\ \text{구매}\ } (\text{사용자}) \xrightarrow{\ \text{구매}\ } (\text{상품 Y})$$

미리 20억 개를 만들어 저장할 필요가 없다. 저장 비용이 0이다.

### 대안 2: 임계값으로 자른다

「함께 산 사람이 $N$명 이상」인 짝만 선으로 남긴다. 원문 저자는 대개 3명이면 충분하다고 하고, 자르는 값은 **엣지 수가 노드 수의 20배를 넘지 않게** 잡는다.

효과가 있는 이유는, 우연히 같이 팔린 짝이 낮은 가중치에 몰려 있기 때문이다. 단, 「1만 버리면 끝」은 아니다. 실험(사용자 2,000명, 상품 300종, $k=20$)에서는 임계값을 1에서 2로 올려도 40,782 → 33,978, 17%만 줄었다. 노드 수의 20배 목표에 들어가려면 임계값 20까지 올려야 했다(3,938개, 13.1배).

**목표로 삼을 것은 임계값 숫자가 아니라 엣지/노드 비율이다.**

### 대안 3: 허브 제거

「비닐봉투」, 「배송비」처럼 거의 모두가 사는 상품, 그리고 수만 개를 사는 봇 계정을 투영 전에 뺀다. $k$가 제곱으로 들어가니 가장 큰 것 몇 개만 빼도 효과가 극적이다.

## 8. 한 장 요약

| 개념 | 식 / 값 |
|---|---|
| 사용자 1명이 만드는 짝 | $\binom{k}{2} = \dfrac{k(k-1)}{2}$ |
| $n$명 전체의 상한 | $n \times \dfrac{k(k-1)}{2}$ |
| $n$에 대한 차수 | 1차 (선형) |
| $k$에 대한 차수 | **2차** — $k$가 2배면 선은 4배 |
| 왜 상한인가 | 같은 짝이 여러 번 만들어져도 선은 하나 |
| 상품 $m$개일 때 또 다른 상한 | $\dfrac{m(m-1)}{2}$ |
| 평균 사용 시 오차 | 정확히 $\dfrac{n \cdot V(k)}{2}$ 만큼 과소평가 |
| 근거 | $k^2$ 이 아래로 볼록 → 옌센 부등식 |

# 고등학생을 위한 설명 — 「가까움」을 숫자로 적을 때 생기는 사고

## 1. 상황: 지하철 노선도에 적힌 숫자

역과 역을 잇는 선 위에 숫자가 하나 적혀 있다고 하자. `8`이다.

이 `8`이 무슨 뜻일까? 두 가지 정반대 해석이 가능하다.

- **거리 해석**: 「이 구간은 8분 걸린다」 → 숫자가 크면 **멀다**.
- **강도 해석**: 「이 두 사람의 친밀도는 8점이다」 → 숫자가 크면 **가깝다**.

숫자만 보고는 구분할 수 없다. 이게 이 카드의 전부다.

## 2. 최단 경로 알고리즘은 한 가지만 안다

「A에서 C까지 가장 좋은 길」을 찾아 주는 프로그램(다익스트라 알고리즘)은 내부에서 이런 판단만 반복한다.

> 지금까지 쌓인 숫자의 **합이 가장 작은** 쪽을 고른다.

수식으로 쓰면, 경로 $P$의 비용을

$$C(P) = \sum_{e \in P} c_e$$

로 정의하고 $C(P)$를 **최소화**한다. 여기서 $c_e$는 각 간선에 붙은 숫자다.

즉 알고리즘은 **작은 값 = 가까움**이라는 규칙 하나로만 세상을 본다. 강도 해석 데이터를 그대로 집어넣으면, 알고리즘은 「친밀도 합이 가장 작은 경로」, 다시 말해 **가장 안 친한 경로**를 「가장 가까운 사이」라고 대답한다.

## 3. 해결: 순서를 뒤집는 함수를 통과시킨다

강도 데이터를 알고리즘이 이해하는 거리 데이터로 **번역**해야 한다. 필요한 성질은 하나다.

> 강도가 클수록 비용이 작아지는 함수, 즉 **단조 감소 함수**를 쓴다.

`ex3_weights.py`가 고른 함수는 가장 단순한 것이다.

$$f(w) = \frac{1}{w} \qquad (w > 0)$$

### 왜 단조 감소인가 (미분으로 확인)

$$f'(w) = -\frac{1}{w^2}$$

$w \ne 0$ 이면 $w^2 > 0$ 이므로 $f'(w) < 0$. 항상 감소한다. 특히 $w > 0$ 구간에서 $f$는 연속이고 계속 줄어든다. 따라서

$$w_1 > w_2 > 0 \;\Longleftrightarrow\; \frac{1}{w_1} < \frac{1}{w_2}$$

크기 순서가 정확히 뒤집힌다. 「강한 간선」이 「짧은 간선」이 된다. 이제 알고리즘의 최소화가 우리가 원하는 최대화 방향과 맞아떨어진다.

코드에서는 딱 한 줄이다.

```python
cost = w if as_distance else 1.0 / w
```

그래프를 만들 때 한 번만 변환하고, 탐색 로직은 전혀 건드리지 않는다.

## 4. 숫자로 확인하기

교재 예제의 간선은 이렇다. (양방향)

$$A \overset{8}{-} B, \quad B \overset{8}{-} C, \quad A \overset{3}{-} D, \quad D \overset{3}{-} C$$

A에서 C로 가는 길은 두 개다.

**거리로 읽으면** (숫자 그대로 더한다)

$$C(A\!\to\! B\!\to\! C) = 8 + 8 = 16, \qquad C(A\!\to\! D\!\to\! C) = 3 + 3 = 6$$

$6 < 16$ 이므로 **A → D → C**가 이긴다.

**강도로 읽으면** (역수를 더한다)

$$C(A\!\to\! B\!\to\! C) = \frac{1}{8} + \frac{1}{8} = 0.25, \qquad C(A\!\to\! D\!\to\! C) = \frac{1}{3} + \frac{1}{3} = \frac{2}{3} \approx 0.667$$

$0.25 < 0.667$ 이므로 **A → B → C**가 이긴다.

**같은 데이터에서 정반대 답이 나왔다.** 숫자에 뜻을 붙이지 않으면 어느 쪽이 맞는지 판정할 방법이 없다.

## 5. 역수 합은 사실 「조화평균」의 친척이다

확률과 통계에서 배운 평균 세 종류를 떠올려 보자. 양수 $a, b$에 대해

$$\text{조화평균} = \frac{2}{\frac 1a + \frac 1b} \;\le\; \text{기하평균} = \sqrt{ab} \;\le\; \text{산술평균} = \frac{a+b}{2}$$

역수 합 $\frac 1a + \frac 1b$ 는 조화평균의 분모다. 조화평균의 특징은 **작은 값 하나가 전체를 크게 끌어내린다**는 것이다. 예를 들어 $a = 100, b = 1$ 이면 산술평균은 50.5로 꽤 크지만 조화평균은 약 1.98밖에 안 된다.

이 성질이 역수 변환에 그대로 따라온다. 즉 `1/w` 합을 최소화하는 것은 「약한 고리가 없는 경로」를 선호하는 것이다. 물리에서 병렬 저항 $\frac{1}{R} = \frac{1}{R_1} + \frac{1}{R_2}$ 를 배웠다면 같은 형태임을 알아볼 수 있다.

### 그래서 「강도 합 최대화」와는 다른 문제다

간선 하나로 이어진 경로 $P_1$ (강도 9)과, 간선 두 개로 이어진 경로 $P_2$ (강도 10, 10)를 비교하자.

- 강도 **합** 기준: $P_1 = 9$, $P_2 = 20$ → $P_2$ 승
- 역수 합 기준: $P_1 = \frac 19 \approx 0.111$, $P_2 = \frac{1}{10} + \frac{1}{10} = 0.2$ → $P_1$ 승

정반대다. 그러니 「역수를 씌우면 강도 최대화가 된다」고 외우면 안 된다. 역수 변환이 보장하는 것은 **간선 하나하나의 순서 뒤집기**뿐이고, 경로 전체의 순서는 도메인이 정한 정의에 따라 달라진다.

## 6. 확률이라면 로그가 정답이다

강도가 「이 연결이 실제로 통할 확률」 $p_e \in (0, 1]$ 이라고 하자. 경로가 끝까지 통할 확률은 (독립을 가정하면) **곱**이다.

$$P(\text{경로}) = \prod_{e \in P} p_e$$

우리는 이 곱을 **최대화**하고 싶다. 하지만 다익스트라는 덧셈만 안다. 여기서 로그가 등장한다.

로그는 **곱을 합으로 바꾸는** 함수다.

$$\log(xy) = \log x + \log y$$

그리고 $\log$는 증가함수이므로, 곱을 최대화하는 것과 로그를 최대화하는 것은 **완전히 같은 문제**다.

$$\max_P \prod_{e \in P} p_e \;=\; \max_P \sum_{e \in P} \log p_e \;=\; \min_P \sum_{e \in P} \left(-\log p_e\right)$$

마지막 단계는 부호를 뒤집으면 최대화가 최소화가 된다는 것뿐이다. 그리고 $0 < p \le 1$ 이면 $\log p \le 0$ 이니 $-\log p \ge 0$, 즉 **비용이 음수가 아니다.** 다익스트라가 요구하는 조건(음수 간선 금지)도 만족한다.

따라서 확률 그래프에서는

$$c_e = -\log p_e$$

로 변환하면 「가장 통할 확률이 높은 경로」를 최단 경로 알고리즘으로 정확히 구할 수 있다. `1/w`가 「순서만 맞추는 편법」인 데 비해, `-log p`는 **원래 문제와 수학적으로 동일한 변환**이다.

## 7. 함정 세 개

1. **$w = 0$**: $1/0$ 은 정의되지 않는다(프로그램은 `ZeroDivisionError`로 죽는다). 강도 0은 실제 데이터에 흔하다. $1/(w + \varepsilon)$ 로 막거나 그 간선을 아예 만들지 않는다.
2. **음수 가중치**: 다익스트라 자체가 음수 간선에서 오답을 낸다. 「이미 확정한 최솟값은 나중에 더 작아지지 않는다」는 가정이 깨지기 때문이다.
3. **$c_e = w_{\max} - w_e$ 로 뒤집기**: 순서는 뒤집히지만, 모든 간선에 상수 $w_{\max}$ 를 더하는 셈이라 **간선 수가 적은 경로가 부당하게 유리**해진다. 게다가 새 데이터로 $w_{\max}$ 가 바뀌면 답도 바뀐다.

## 8. 한 줄로 남길 것

> 최단 경로 알고리즘은 **항상 「작을수록 가깝다」**로 읽는다. 강도 데이터는 반드시 단조 감소 함수로 거리로 번역해서 넣어야 하고, 어떤 함수를 쓸지는 「경로의 강도를 합으로 볼지 곱으로 볼지」가 결정한다.

그리고 애초에 사고를 막는 가장 싼 방법은 이름이다. `weight` 대신 `cost_minutes`, `affinity_score`.

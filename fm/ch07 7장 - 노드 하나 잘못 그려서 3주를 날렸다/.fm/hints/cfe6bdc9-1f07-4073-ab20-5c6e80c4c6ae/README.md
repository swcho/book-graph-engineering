# 자기 루프가 함정인 이유

> **Q.** 자기 루프가 함정인 이유는 무엇인가?
>
> **A.** 알고리즘마다 1로 세기도 하고 2로 세기도 해서, 라이브러리를 바꾸면 숫자가 조용히 달라진다. 미리 걸러 두는 편이 낫다.

출처: 7장 「노드 하나 잘못 그려서 3주를 날렸다」, 7.4절 *두 종류만 있는 그래프, 그리고 겹치는 엣지* / `code/ex5_multigraph.py`

---

## 1. 자기 루프란

**자기 루프(self-loop)** 는 시작 노드와 끝 노드가 같은 엣지다. `(A)-[:X]->(A)`.

예제 5의 엣지 목록 마지막 줄이 그것이다.

```python
EDGES = [
    ("가온테크",   "나루소프트", "C-2023-011"),
    ("가온테크",   "나루소프트", "C-2024-088"),
    ("가온테크",   "나루소프트", "C-2025-118"),
    ("가온테크",   "다올물산",   "C-2025-200"),
    ("라온에너지", "라온에너지", "C-2025-301"),   # 자기 루프
]
```

계열사가 자기 자신에게 대여한 계약, 계정 하나가 자기 자신에게 송금한 거래, 페이지가 자기 자신을 링크한 것. 데이터를 그대로 옮기면 이런 게 반드시 섞여 들어온다. 지우려고 만드는 게 아니라 **그냥 생긴다**는 점이 중요하다.

## 2. 왜 1도 2도 답이 되는가

무향 그래프의 차수는 「그 노드에 붙은 엣지 끝(edge endpoint)의 개수」로 정의된다. 자기 루프는 양 끝이 모두 같은 노드에 붙으므로 끝이 2개다. 그래서 **차수 2**.

이 정의를 쓰는 이유는 악수 정리(handshaking lemma)가 깨지지 않게 하기 위해서다.

```
Σ deg(v) = 2·|E|
```

자기 루프를 1로 세면 엣지 하나가 왼쪽에 1만 기여해서 이 등식이 무너지고, 인접행렬·라플라시안·스펙트럼 계산이 전부 어긋난다. 그래서 **그래프 이론의 기본 관례는 2**다.

그런데 사람이 데이터를 볼 때의 직관은 다르다. 「라온에너지가 관계를 몇 개 갖고 있나?」 하면 계약서는 한 장이므로 **1**이라고 답하고 싶다. 구현자가 도메인 감각으로 코드를 쓰면 1이 나온다.

즉 1과 2는 버그와 정답의 관계가 아니라, **서로 다른 두 관례**다. 그래서 어느 쪽도 예외를 던지지 않고 조용히 통과한다.

예제 5의 `degree_multi`가 이 관례를 명시적으로 적어 둔 이유가 그것이다.

```python
def degree_multi(edges):
    """다중 그래프로 보면: 엣지마다 센다. 자기 루프는 2로 센다(관례)."""
    deg = Counter()
    for a, b, _ in edges:
        if a == b:
            deg[a] += 2      # ← 여기가 갈리는 지점
        else:
            deg[a] += 1
            deg[b] += 1
    return deg
```

`degree_simple`은 아예 다른 선택을 한다.

```python
pairs = {(min(a, b), max(a, b)) for a, b, _ in edges if a != b}
#                                                      ^^^^^^^^ 자기 루프를 버린다 → 차수 0
```

같은 파일 안에서도 자기 루프의 차수가 **0이냐 2냐**로 갈린다. 라이브러리를 넘나들면 말할 것도 없다.

## 3. 실제로 갈리는 자리

| 계산 | 자기 루프 취급 |
|---|---|
| 무향 차수 (그래프 이론 관례) | **2** |
| 유향 그래프의 in-degree / out-degree | 각각 **1** (합치면 2) |
| 인접행렬 대각원소 (NetworkX `adjacency_matrix`) | **1** (또는 가중치값) → 행 합으로 차수를 구하면 1이 나온다 |
| 삼각형 수 / 군집 계수 (NetworkX `triangles`, `clustering`) | **무시** |
| 최단 경로 (다익스트라, BFS) | **무시** (자기에게 가는 비용은 쓸 일이 없다) |
| PageRank | 무시되지 않고 **자기 점수를 자기에게 되먹인다** → 순위가 부풀려진다 |
| 모듈러리티 / 커뮤니티 탐지 | 노드 자신의 내부 엣지로 계산에 **들어간다** |
| 매개 중심성 (betweenness) | **무시** |

특히 **NetworkX의 차수 함수와 인접행렬이 서로 다른 값을 준다**는 게 대표적인 함정이다. `G.degree(v)`는 자기 루프를 2로 세는 관례를 따르는데, `nx.adjacency_matrix(G)`는 대각원소에 1(혹은 가중치)을 넣는다. 그래서 「행렬 행 합 = 차수」라고 믿고 쓴 코드는 자기 루프가 있는 노드에서만 값이 1 어긋난다.

igraph도 이 문제를 스스로 이슈로 올려 두었다. 함수마다 자기 루프 처리가 달라서, 「세지 않음 / 1로 셈 / 2로 셈」 세 가지 모드를 분리하자는 제안이 igraph 이슈 #1193이다. 즉 **한 라이브러리 안에서도 일관되지 않다**는 뜻이다.

## 4. 왜 「조용히」가 최악인가

자기 루프는 오류를 만들지 않는다.

- 예외가 안 난다. 스택 트레이스도 없다.
- 테스트도 대개 통과한다. 자기 루프가 없는 작은 픽스처로 테스트를 쓰기 때문이다.
- 결과가 「그럴듯한 숫자」로 나온다. 차수 2가 4로 보이거나 중심성 순위 3위가 1위로 올라가는 정도라서 육안으로는 이상해 보이지 않는다.
- 라이브러리 버전을 올리거나 NetworkX → igraph → Neo4j GDS로 옮기는 순간 숫자가 바뀐다. 그런데 그때 바뀐 코드는 「라이브러리 교체」뿐이라, 원인을 자기 루프로 의심하기까지 오래 걸린다.

이게 7장의 제목(「노드 하나 잘못 그려서 3주를 날렸다」)과 3절의 가중치 사고(친밀도를 최단 경로에 넣어 2주 만에 발견)와 같은 종류의 사고다. **터지지 않고 틀린다**는 점이 공통점이다.

## 5. 그래서 어떻게 하는가 — 「미리 걸러 두는 편이 낫다」

답의 후반부가 처방이다. 계산 시점에 관례를 맞추려 하지 말고, **적재 시점에 결정해서 데이터에서 없애 둔다.**

1. **적재 파이프라인에서 `src == dst`를 명시적으로 처리한다.** 세 갈래 중 하나를 고른다.
   - 버린다 (분석에 의미 없는 잡음일 때 — 자기 자신 링크, 데이터 오류)
   - 별도 노드 속성으로 옮긴다 (`self_loan_count: 1` 처럼) — 정보는 남기면서 그래프 알고리즘에서 빼는 방법이다. 7.1절의 「승격/강등」 판단과 같은 결이다.
   - 남긴다. 단 이때는 **어느 관례로 세는지를 문서와 이름에 박아 둔다.**
2. **적재 시 자기 루프 개수를 로그로 남긴다.** 0건일 것 같던 데이터에서 1,200건이 나오면, 그 자체가 도메인을 잘못 이해했다는 신호다.
3. **자기 루프가 있는 픽스처로 테스트를 쓴다.** 예제 5의 `EDGES`가 자기 루프를 일부러 한 줄 넣어 둔 이유다.
4. **차수와 중심성 결과를 회귀 테스트로 고정한다.** 라이브러리 업그레이드로 숫자가 조용히 달라지는 사고는 이 테스트 하나로 시끄럽게 바뀐다.
5. **이름에 뜻을 박는다.** 7.3절의 `weight` → `cost_minutes` 교훈과 같다. `degree`보다 `partner_count`(단순 그래프, 자기 루프 제외) / `contract_count`(다중 그래프, 자기 루프 2로 셈)가 낫다.

## 6. 다중 엣지와의 관계

7.4절은 다중 엣지와 자기 루프를 한 묶음으로 다룬다. 둘의 공통점이 **「무엇을 세는지」에 따라 답이 달라지는데 어느 답도 오류가 아니라는 것**이다.

예제 5의 출력에서 가온테크의 차수는 단순 그래프로 2, 다중 그래프로 4다.

```
가온테크의 차수가 2 냐 4 냐. 둘 다 맞다. 무엇을 세는지가 다를 뿐이다.
  거래처 수를 알고 싶으면 단순 그래프.
  거래 건수를 알고 싶으면 다중 그래프.
```

사고는 이 둘을 **섞을 때** 난다. 중심성을 다중 그래프로 계산해 놓고 「거래처가 많은 회사」라고 보고하면, 한 회사와 계약을 여러 번 한 곳이 1등이 된다. 자기 루프는 여기에 한 겹을 더 얹는다. 「거래처 수」를 보고하는데 자기 자신이 거래처 목록에 끼어 있는 셈이다.

## 7. 한 줄 정리

자기 루프는 **정답이 두 개(1과 2)이고 둘 다 표준이라서** 함정이다. 오류로 터지는 대신 라이브러리·함수·버전을 바꿀 때 숫자만 조용히 흔들린다. 계산 시점에 관례를 맞추려 하지 말고 적재 시점에 명시적으로 걸러 두는 것이, 나중에 3주를 날리지 않는 값싼 보험이다.
